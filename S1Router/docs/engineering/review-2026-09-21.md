## Repairs to existing behavior

- R-009/R-011: reject deeply nested frames and invalid/oversized identifiers safely;
  emit registered cancellation reasons; callbacks run outside the admission lock;
  metric increments are synchronized. Regression reproduced the callback deadlock.
- R-009: SIGTERM only requests stopping; normal control flow drains work. Restore the
  previous signal handler even on input failure. Regression reproduced lock-taking
  inside the signal handler, plus real subprocess shutdown checks.
- R-006: complete breaker bookkeeping before publishing an automatic answer. A failed
  completion leaves review-required, no selected answer, and conservative cost settlement.
- M-002/M-003: malformed ingestion fields now yield typed validation errors; group_id
  joins split leakage checks, and assignment validates its result before returning it.
- M-008: no baseline is inferred from held-out labels. Callers may supply independently
  frozen per-example baseline predictions; absent inputs report comparison unavailable.
  Empty-accept slices report undefined error; duplicate IDs cannot inflate counts.
- R-013: latency drill restored to the specified sample count and p95 threshold; it
  prints machine/Python/payload/p50/p95/p99 context. Its fixed synthetic payload and
  fake provider do not prove model quality or full resource readiness.
- Product imports are mandatory in tests; missing implementation must fail collection,
  rather than silently skip via `importorskip`.
